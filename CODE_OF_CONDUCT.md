# Code de conduite

## Notre engagement

Un environnement accueillant et bienveillant pour toutes les personnes contribuant
au projet (code, pédagogie, contenus, tests terrain), sans distinction d'âge,
de genre, d'origine, de handicap ou de niveau technique.

## Comportements attendus

- Bienveillance envers les débutants ; le projet accueille des enseignants et
  éducateurs non développeurs
- Critique des idées, jamais des personnes
- Focus sur ce qui sert les participants et les animateurs de terrain

## Comportements inacceptables

Harcèlement, propos discriminatoires ou dénigrants, publication de données
personnelles d'autrui.

## Application

Signalement aux mainteneurs du projet. Non-respect répété ⇒ exclusion de la
communauté. Ce code s'applique aussi aux contenus pédagogiques soumis au projet.
