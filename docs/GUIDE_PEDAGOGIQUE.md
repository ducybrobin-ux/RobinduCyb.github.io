# Guide Pédagogique — Objectifs, compétences, évaluation

Ce document défint les fondamentaux pédagogiques de Curi🧭s et comment les exploiter en contexte éducatif.

---

## 1. Philosophie

> « On n'apprend pas à jouer. On apprend en jouant. »

Curi🧭s n'est pas un outil de « gamification » superficiel. Le jeu est un **vecteur d'apprentissage** qui permet de :

- **Expérimenter** dans un contexte sécurisé
- **Coopérer** pour résoudre des problèmes
- **Observer** le territoire et les autres
- **Réfléchir** sur ses propres processus cognitifs

## 2. Cadre de référence

### 2.1 Taxonomie de Bloom (révisée)

Niveaux mobilisés dans Curi🧭s :

| Niveau | Activité Curi🧭s | Exemple |
|--------|------------------|---------|
| **Retenir** | Identifier, nommer | Reconnaître un arbre, un son |
| **Comprendre** | Expliquer, décrire | Décrire le rôle d'un pollinisateur |
| **Appliquer** | Résoudre, utiliser | Calculer une distance, interpréter une carte |
| **Analyser** | Distinguer, comparer | Séparer fait/opinion, comparer deux hypothèses |
| **Évaluer** | Critiquer, juger | Évaluer la fiabilité d'une source |
| **Créer** | Concevoir, produire | Proposer une solution, rédiger un compte-rendu |

### 2.2 Compétences psychosociales (OMS)

| Compétence | Déclinaison dans Curi🧭s |
|------------|--------------------------|

| **Relationnel** | Travailler en équipe, s'entraider |

### 2.3 Éducation au développement durable (EDD)

| Dimension | Mobilisation |
|-----------|--------------|
| **Environnementale** | Observation du vivant, biodiversité, climat |
| **Sociale** | Coopération, solidarité, citoyenneté |

## 4. Différenciation pédagogique

### 4.1 Niveaux de difficulté

Curi🧭s propose **3 niveaux par énigme**, calibrés par tranche d'âge :

| Niveau | Tranche | Caractéristiques |
|--------|---------|------------------|
| **Facile** | 6-9 ans | Phrases courtes, vocabulaire simple, indices multiples |
| **Moyen** | 10-13 ans | raisonnement requis, une seule bonne réponse |
| **Difficile** | 14+ ans | Abstraction, pièges, raisonnement multiple |

### 4.2 Adaptation automatique

Le système d'adaptation (`packages/analytics`) ajuste en temps réel :

- **Indices gradués** : après X tentatives, un indice apparaît
- **Missions bonus** : débloquées après un score suffisant
- **Difficulté suggérée** : le système recommande un niveau adapté

### 4.3 Accessibilité

| Besoin | Adaptation |
|--------|------------|
| **Déficience visuelle** | Audio, description textuelle, QR codes sonores |
| **Déficience motrice** | GPS automatique, validation à distance |
| **Déficience auditive** | Transcription, indices visuels |
| **Multilingue** | 6 langues (fr/en/nl/de/zh/ja) |
| **Handicap cognitif** | Niveau facile, indices supplémentaires |

## 5. Évaluation

### 5.1 Types d'évaluation

| Type | Moment | Usage |
|------|--------|-------|
| **Diagnostique** | Avant la session | Connaissances préalables |
| **Formative** | Pendant la session | Ajuster l'accompagnement |
| **Sommative** | Après la session | Bilan des apprentissages |

### 5.2 Indicateurs observables

| Indicateur | Observation | Preuve |
|------------|-------------|--------|
| **Progression** | Nombre de balises complétées | Dashboard |
| **Engagement** | Temps passé, tentatives | Analytics |
| **Coopération** | Échanges entre participants | Observation |
| **Persévérance** | Nombre de tentatives avant succès | Analytics |
| **Compréhension** | Qualité des réponses | Quiz scores |

### 5.3 Débriefing

Le débriefing est **essentiel**. Il transforme l'expérience en apprentissage.

**Guide de débriefing** :

1. **Réaction** : « Qu'avez-vous ressenti ? »
2. **Observation** : « Qu'avez-vous remarqué ? »
3. **Conceptualisation** : « Qu'avez-vous appris ? »
4. **Application** : « Comment utiliser ce que vous avez appris ? »

### 5.4 Données collectées (analytics locales)

Les métriques restent **locales** (pas de serveur externe) :

- Temps par balise
- Nombre de tentatives par énigme
- Indices utilisés
- Score quiz
- Progression globale
- Détection de blocages
