# 🧠 JDP_BC — Jeu de piste Biais Cognitif

**Bienvenue sur le wiki du projet JDP_BC**, une application web progressive (PWA) 100 % française qui transforme un sentier en parcours de lucidité : huit balises, huit pièges mentaux à démasquer en famille.

## En deux minutes

1. Double-cliquez sur `demarrer_serveur.cmd`.
2. Les familles scannent le **QR Wi-Fi**, puis le **QR du jeu** (imprimables depuis le [tableau de bord](Organisation-et-tableau-de-bord)).
3. Chaque équipe crée son profil et suit le sentier : énigme → signature sonore → quiz.
4. Le soir, le palmarès désigne les esprits les plus affûtés. 🏆
