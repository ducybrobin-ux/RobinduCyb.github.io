Documentation

Guides, référence technique et bonnes pratiques.

🚀 Démarrage rapide

Lancez votre premier parcours en 3 étapes.

  1. Ouvrez le Hub et créez un compte
  2. Créez un parcours avec le Studio
  3. Configurez la session depuis le Dashboard

🎨 Studio de création

Le Studio guide votre création en 8 étapes : Objectifs → Public → Territoire → Missions → Événements → Débriefing → Tests → Publication. Chaque étape a des champs obligatoires et une validation automatique.

✏️ Éditeur de contenu

L'éditeur permet de modifier directement les balises, découvertes, quiz et guide. Il inclut un éditeur de carte (Leaflet/OpenStreetMap), un browser d'images, et l'import/export KML.

🧩 Atelier de packs

L'Atelier crée des bundles de contenu réutilisables : balises, découvertes, guide, quiz et événements. Exportez en JSON et importez avec node tools/import-pack.mjs.

🎛️ Dashboard organisateur

Le Dashboard affiche : message broadcast, suivi GPS des équipes, validations par balise, épreuves aléatoires, QR codes de connexion, configuration serveur (Local/Internet), et gestion des urgences.

📱 Player mobile (PWA)

Le Player est une Progressive Web App complète : carte interactive, scan QR, GPS, boussole, énigmes à 3 niveaux de difficulté, quiz, carnet d'observation, palmarès, reconnaissance sonore et mode course. Fonctionne entièrement hors-ligne.

🔧 Installation serveur

Le serveur CURIOS est en Node.js, zéro dépendance externe.

node packages/server/src/index.js

Le serveur démarre sur le port 8080. La première connexion définit le mot de passe organisateur.
